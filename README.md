# 【最新版】likeshop 连锁点餐系统 - PHP 版 + uniapp 前端全开源

最新版 likeshop 连锁点餐系统，PHP 后端搭配 UniApp 前端，整套代码全开源，采用总部 + 多门店架构，适配餐饮连锁品牌数字化经营。UniApp 前端支持微信、支付宝、抖音小程序以及 H5，一套代码多端发布，大幅降低开发与维护成本。

系统覆盖扫码堂食点餐、外卖配送、到店自提、桌台管理，订单可直连后厨打印小票、订单核销。总部统一管控菜品、会员、营销活动；各门店拥有独立后台，可单独维护菜品库存、定价，权限相互隔离。内置会员储值、优惠券、满减等营销工具，配套收银台，支持线下结账、退款对账，实时查看全门店营收数据报表。

源码无加密，代码结构清晰，支持私有化部署至自有服务器，经营数据自主掌控，方便深度二次开发。部署简单，导入数据库、配置支付等接口即可快速上线。适配中餐、火锅、奶茶、快餐等连锁门店，搭建品牌自有私域点餐平台，规避外卖平台高额抽成，实现线上线下一体化餐饮数字化管理。
